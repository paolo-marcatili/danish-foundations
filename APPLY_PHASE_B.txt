Danish Foundations Phase B

This update fixes the Phase A pre-reader audio behavior and expands the Danish app through Chapters 0-4.

Apply from the existing hero-language-camp repository root:

  unzip -o ~/Downloads/danish-foundations-phase-b-update.zip -d .
  npm install
  npm run check:danish
  npm run dev:danish

Open http://localhost:5174

GitHub Pages build:

  GITHUB_PAGES=true GITHUB_PAGES_BASE=/danish-foundations/ npm run build:danish

Then commit and push the changed files.

Audio generation:

  npm run content:audio:danish:plan

See docs/DANISH_AUDIO_GENERATION.md for the review-sample and complete Azure workflow.

# Eastern Armenian through Italian

This is the default modular language pack for the MVP.

- `pack.yaml`: language metadata and file map
- `interface.yaml`: Italian interface/menu text
- `tags.yaml`: controlled semantic tags
- `tasks.yaml`: training tasks and figurative encounters
- `levels.yaml`: level caps and fight gate rules
- `enemies.yaml`: monsters, topic tags, rewards and difficulty
- `dictionary/*.jsonl`: words, letters and sentence-order items
- `audio/human`: community recordings
- `audio/auto`: generated preview audio

Human audio is preferred. Automatic audio is opt-in in gameplay.

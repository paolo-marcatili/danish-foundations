# Source material for `hy-eastern-it`

This directory keeps the provenance needed to review the expanded language pack.
None of the automatically matched spellings or meanings should be treated as
more authoritative than a fluent Eastern Armenian reviewer.

## User-provided material

- `gist-vocabulary.json` — structured transcription of the family Quizzario gist.
- `archive-extracted-redacted.txt` — deterministic, name-redacted paragraph/table extraction from the uploaded lessons.
- `private-archive-docx/` is intentionally ignored; place the original DOCX files there locally when rerunning extraction.

Personal details in the public learning content are replaced with generic names
and examples. The original uploaded documents are intentionally excluded from Git. Keep them only in the ignored local `private-archive-docx/` folder.

## Open-source reference lists

- `eng_arm.csv` and `eng_arm_rom.csv` come from
  `shay-ellison/armenian-words` (MIT license). They provide draft Armenian
  spellings and romanization. The upstream project itself asks users to validate
  transliterations against its published guidelines.
- `italian-vocab.tsv` comes from `tomcumming/italian-vocab` (MIT license), which
  combines an Italian frequency list with FreeDict English meanings.

The pack builder matches the two reference lists by English gloss. Polysemy can
produce an incorrect Italian sense, so every automatic match is marked
`needs_native_speaker_review` and listed in `content-review-report.md`.

## Rebuild

```bash
npm run content:extract-docx
npm run content:expand
npm run validate:content
```

No synthetic audio is generated by this process. New entries therefore remain
unavailable to audio-required exercises while **Solo voci reali** is enabled.

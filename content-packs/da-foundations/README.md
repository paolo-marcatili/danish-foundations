# Ord- og Talheltene — Phase B

Danish early-literacy and mathematics curriculum for a bilingual child beginning Danish primary school.

The child-facing language is Danish. Italian appears only as optional parent support in the chapter reader.

## Current scope

- Five chapters, Levels 0–4.
- Seventeen introduced graphemes.
- Thirty-four picture-supported first words.
- Sound-led letter recognition using complete example words.
- Uppercase/lowercase matching as a secondary activity.
- Picture-to-word matching and letter-tile word building.
- Number recognition, counting, ordering and comparison from 0 to 10.
- Addition and subtraction with visible objects.
- Seventy-one structured mathematics problems.
- One reusable labyrinth and five scalable enemies.
- Automatic Danish narration and replay for every task.

Browser speech is the immediate fallback. Use `tools/generate-danish-audio.mjs` to generate reviewed fixed MP3 files for letter names, words and full math prompts. Isolated phonemes are intentionally reserved for human recordings.

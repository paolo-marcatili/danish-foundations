# Ord- og Talheltene — Phase A

Technical vertical slice for Danish early literacy and mathematics.

The prototype includes five graphemes (`s`, `o`, `l`, `m`, `a`), two decodable words, quantities 0–5, early addition/subtraction, one chapter, one labyrinth, and one reusable enemy.

Child-facing copy is Danish. Italian text is included in the chapter and content records for parent support.

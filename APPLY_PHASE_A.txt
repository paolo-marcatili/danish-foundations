Danish Foundations — Phase A update

Apply this archive to the root of the existing Hero Language Camp repository:

  unzip -o danish-foundations-phase-a-update.zip -d /path/to/hero-language-camp
  cd /path/to/hero-language-camp
  npm install
  npm run check:danish
  npm run dev:danish

Open http://localhost:5174.

GitHub Pages build:

  GITHUB_PAGES=true GITHUB_PAGES_BASE=/danish-foundations/ npm run build:danish

The Danish deployment workflow runs automatically only in a repository named
"danish-foundations". The Armenian workflow runs only in "hero-language-camp".
See docs/DANISH_FOUNDATIONS_PHASE_A.md for scope and limitations.

# Labyrinth AI atlas source

`labyrinth-ai-atlas.png` is the source composition used for the v0.11.5 labyrinth art pass.

It was generated from the project brief:

> Semi-realistic hand-painted fantasy RPG isometric assets, enchanted forest ruins, lush moss and roots, warm storybook colors, natural warm lighting, child-friendly silhouettes, transparent game objects, and atmospheric painted backdrops.

Use `npm run assets:extract-labyrinth-ai` to recreate the normalized runtime files.

# v0.10.4 graphics renderer refactor, Commit B

This commit is the graphics/renderer half of the v0.10.3/v0.10.4 split. It does not change learning formulas, fight formulas, item memory, language-pack content, or progression rules.

## Layer naming

The active parallax layers are now named by depth and purpose:

```text
layer-00-sky.png
layer-01-far-mountains.png
layer-02-far-hills.png
layer-03-mid-hills.png
layer-04-sparse-forest.png
layer-05-village-back.png
layer-06-path-ground.png
```

The layer configuration lives in:

```text
apps/web/src/worldConfig.ts
```

Each layer has a depth, speed, screen position, size, and asset path. The Phaser renderer skips missing parallax textures, so a future asset pack can omit layers.

## Object placement

Objects are no longer positioned as one random collection around the hero path. They are assigned to object layers:

```text
farBack
behindHeroLarge
pathBack
foreground
```

Each object layer declares:

```text
anchorLayerId
parallax speed inherited from that layer
depth
groundY
allowed object kinds
scale range
spawn gaps
```

Depth order is controlled by:

```text
apps/web/src/worldConfig.ts -> DEPTH
```

The important order is:

```text
large/path-back objects < hero < foreground objects
```

## Asset sheets

The active object sheets are:

```text
objects-small.png   48x48
objects-large.png   96x96
objects-front.png   64x64
```

The `OBJECT_FRAMES` map in `worldConfig.ts` maps a semantic object kind to its sheet and frame number.

## Hero equipment overlays

Sword, shield, and armor overlays still use the same frame grid as the hero. The renderer now forces each visible overlay to the current hero frame every update, which prevents equipment from drifting or playing a different animation phase.

The companion remains a separate sprite that follows behind the hero.

## Asset workflow

Edit source assets here:

```text
asset-packs/cc0-pixel-v10/
```

Then sync into the served runtime folder:

```bash
npm run assets:sync
```

`npm run assets:generate` is still safe and only syncs. To regenerate placeholder assets, use:

```bash
npm run assets:generate-parallax
```

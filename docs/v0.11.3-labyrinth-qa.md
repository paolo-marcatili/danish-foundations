# v0.11.3 — Labyrinth integration QA

This maintenance release hardens the v0.11.2 enchanted-forest labyrinth.

## Fixes

- Saves the final learner state synchronously before removing a completed or
  failed labyrinth autosave, reducing the chance of losing rewards or review
  memory if the app closes immediately afterward.
- Clamps restored heart values against the restored maximum and rejects
  negative XP/path baselines in saved sessions.
- Allows content complexity `0`, which is used by the starter pack for
  introductory and pre-reading material.
- Retains the existing protections against pausing or abandoning during the
  short answer-feedback transition.

## Verification performed

- Content-schema and learning-engine TypeScript checks.
- Web-source TypeScript check with local module stubs.
- Modular pack parsing and schema validation.
- 250 seeded maze-generation tests.
- Connectivity, rune distribution, 35-question budget, treasure-lock, guardian,
  session sanitization, stat rewards, and level-session-credit tests.
- Dragon runtime/source sheet dimension and RGBA checks.

The Armenian demo content still intentionally reports native-speaker review
warnings.

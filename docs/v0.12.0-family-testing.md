# v0.12.0 — family testing, responsive sessions, and expanded Armenian pack

## Interface and mobile layout

- Training and fights use a fixed session layout: the Phaser side-scroller and
  answer panel no longer resize each other.
- Desktop uses a side-by-side layout; phones use a fixed game viewport and an
  internally scrolling question sheet.
- The labyrinth map remains mounted during questions.
- The labyrinth dragon token is removed; the dragon remains in the side-scroller.
- Resolved labyrinth events remain visible at approximately 84% opacity.
- A persistent translated adventure log records movement, discoveries, answers,
  hearts, runes, monsters, caches, healing, reveal events, and treasure state.
- Settings include forced desktop and phone/tablet viewport simulations, with an
  optional decorative device frame.
- The Story/Task panel expands to show pack-authored chapters and readings.

## Labyrinth walls

The four canonical low single-edge walls retain their exact 256×192 geometry.
An image-to-image source pass adds warmer mossy-stone texture, while the original
alpha masks preserve wall endpoints and every legal wall combination.

## Content

The draft `hy-eastern-it` pack now contains:

```text
620 vocabulary / useful-phrase entries
260 sentence exercises
39 modern Armenian letters
```

Sources and provenance are stored under `content-packs/hy-eastern-it/sources/`.
The importer does not generate new audio. Automatically matched spellings and
Italian meanings remain marked `needs_native_speaker_review` and are listed in
the review report.

Original family DOCX files are intentionally excluded from Git. A redacted
extraction is included; private originals can be placed in the ignored
`private-archive-docx/` directory when rebuilding.

## Repository and phone testing

- Git LFS rules are included for artwork, audio, ZIP, and DOCX files.
- A web manifest and phone icons are included.
- `npm run dev:lan` supports quick same-Wi-Fi browser testing.
- Capacitor remains configured for `org.herolanguagecamp.app`.
- Detailed first-Git, Xcode/iPhone, Android, content, privacy, and troubleshooting
  guides are included under `docs/`.

# v0.4 pixel/audio/admin update

This iteration focuses on gameplay readability, audio reliability, community contribution flow, and smoother path encounters.

## Game changes

- Training and fight sessions now live in a bottom play tray instead of covering the path.
- The path stays visible on mobile and desktop while answering questions.
- The hero continues walking into an encounter before the question tray opens.
- The randomly generated path curves, narrows, widens, rises, and falls slightly.
- Scenery now scrolls from right to left and is layered as far background, path-side objects, hero/encounter, and foreground.
- The hero has a more distinct pixel-art look: hair, scarf, cheeks, backpack, tunic star, optional hat/cape/pet/items.
- Training encounters use visual mini-challenges:
  - Vocabulary / Power: lift a stone
  - Listening / Shield: shield drill
  - Pronunciation / Accuracy: target throw
  - Grammar / Strategy: puzzle gate
  - Letters / Accuracy: letter gate
- Fight answers now map to different animations:
  - Vocabulary: strength attack
  - Listening: parry/block
  - Pronunciation/letters: dagger throw
  - Grammar: strategy spell
- Fart attack now has a small green cloud.
- Monsters have hit, attack, and defeat animations.

## UI changes

- Long prompts and answer options use a fitted-text component so longer words shrink instead of overflowing.
- Training/fight question panels are positioned below the path rather than as fixed overlays.
- The interface remains a single unified phone-style app, but it has wider desktop constraints.

## Audio changes

- Existing Armenian words, letters, and sentences now have automated eSpeak `.wav` preview audio.
- The app plays local audio first and only falls back to browser speech synthesis if needed.
- Human/community audio takes priority over automated audio.
- Added `source_type` metadata to audio references: `human`, `automated`, or `browser_tts`.

## Contribution/admin changes

- Added an in-app content admin panel behind the `🛠️` button.
- The admin panel can record audio in the browser and download a JSON contribution file.
- Added a duplicate-safe merge script:

```bash
npm run content:merge -- ./contribution.json
```

- Added an automated audio generator:

```bash
npm run content:auto-audio
```

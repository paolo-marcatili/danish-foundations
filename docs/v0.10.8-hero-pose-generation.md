# v0.10.8 — explicit hero pose generation

This update replaces the loosely defined hero guide with an explicit 12-row,
8-frame pose system.

## Fixed character design

Every frame uses the same equipment and clothing:

- sword in the character's left hand;
- shield in the character's right hand;
- green cape;
- brown shirt;
- belt;
- brown pants;
- no extra equipment.

The hero faces right. In the side-view guide, the sword hand is the forward,
screen-right hand and the shield hand is the screen-left hand.

## Animation grid

`hero-adventurer.png` is 1024 × 1536 px:

- 8 columns;
- 12 rows;
- 128 × 128 px per frame.

Rows:

0. idle — eight identical defensive poses;
1. walk — left foot forward, feet together, right foot forward, feet together;
2. small jump — feet lift only slightly and remain inside the cell;
3. sword swing;
4. short airborne lunge / special attack with trailing cape;
5. shield defend / parry;
6. hit, fall on the back, and get up;
7. victory sword raise without jumping;
8. strength training squats;
9. defense training shield drill;
10. precision training sword toss, flip, and catch;
11. stamina training energy ball growth and contraction.

## Files

Exact vector pose guide:

```text
asset-packs/cc0-pixel-v10/sources/guides/hero-adventurer-pose-guide.svg
```

Transparent raster guide:

```text
asset-packs/cc0-pixel-v10/sources/guides/hero-adventurer-pose-guide.png
```

Image-to-image source output:

```text
asset-packs/cc0-pixel-v10/sources/image-to-image/hero-adventurer-dalle-concept.png
```

Pose-faithful rendered derivative:

```text
asset-packs/cc0-pixel-v10/sources/rendered/hero-adventurer-rendered.png
```

Active runtime sprite:

```text
asset-packs/cc0-pixel-v10/hero-adventurer.png
```

The raw image-to-image result is retained as a style reference because image
models can alter the number of rows, columns, or poses. The renderer script
transfers its warm painterly texture onto the exact guide grid, preserving the
Phaser frame layout.

## Commands

Regenerate only the hero guide and rendered version:

```bash
npm run assets:generate-hero-poses
```

Regenerate all simplified guide assets:

```bash
npm run assets:generate-guides
```

Edit durable source files in `asset-packs/cc0-pixel-v10/`, then sync them to the
Vite public directory with:

```bash
npm run assets:sync
```

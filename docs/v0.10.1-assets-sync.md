# v0.10.1 asset sync and concept sprite sheet

This small update separates the **source asset pack** from the **runtime served copy**.

## New commands

```bash
npm run assets:sync
```

Copies the source asset pack from:

```text
asset-packs/cc0-pixel-v10/
```

to the Vite/Phaser runtime folder:

```text
apps/web/public/assets/pixel/
```

`npm run assets:generate` is now a safe alias for `npm run assets:sync`, so it no
longer regenerates placeholder art and overwrites manual edits.

The old procedural generator is still available under a more explicit name:

```bash
npm run assets:generate-placeholders
```

Use that command only when you intentionally want to recreate the simple
placeholder assets.

## Cleaned concept sprite

A new experimental sprite sheet was added:

```text
asset-packs/cc0-pixel-v10/hero-adventurer.png
apps/web/public/assets/pixel/hero-adventurer.png
```

It uses 96x96 frames and is available in Settings as the `Avventuriero` sprite
set.

The concept source image is stored in:

```text
asset-packs/cc0-pixel-v10/sources/hero-adventurer-concept.png
```

To regenerate the transparent sheet from the concept source:

```bash
python -m pip install -r requirements-dev.txt
npm run assets:clean-concept
```

The extraction is intentionally marked experimental. It creates a usable
transparent sheet, but artist retouching will still produce better production
sprites.

# v0.11.0 — 25-frame multi-sheet hero animations

This release replaces the previous 8-frame-per-row monolithic hero atlas with
seven user-supplied animation sheets. Each source sheet is a transparent
`1280 x 1280` PNG arranged as a `5 x 5` grid of `256 x 256` frames.

## Runtime files

```text
hero-walk.png
hero-attack-simple.png
hero-attack-swing.png
hero-fall.png
hero-energy-ball.png
hero-parry.png
hero-victory.png
```

The renderer keeps the files separate instead of packing them into a
6,400-pixel-wide atlas. This is safer for mobile WebGL implementations and
allows one animation to be replaced independently.

## Animation mapping

```text
idle               walk frame 0
walk/run            hero-walk.png
attack1             hero-attack-simple.png
attack2/special     hero-attack-swing.png
fall/hit            hero-fall.png
energy ball         hero-energy-ball.png
defend/parry        hero-parry.png
victory             hero-victory.png
```

Training uses:

```text
strength    attack swing, looping
defense     parry, looping
precision   simple attack, looping
stamina     energy ball, looping
```

The four training animations keep looping while a training session is active.
A temporary feedback action returns to the appropriate training loop rather
than returning to idle.

## Importing replacement files

The bundled originals are stored in:

```text
asset-packs/cc0-pixel-v10/sources/hero-animation-sheets/
```

To re-import them:

```bash
npm run assets:import-hero-and-sync
```

To import another directory or ZIP:

```bash
npm run assets:import-hero -- /absolute/path/to/spritesheet.zip
npm run assets:sync
```

Accepted source filenames include the supplied `Leo-*-v1.png` names as well as
short aliases such as `walk.png`, `attack.png`, `swing.png`, and `parry.png`.

The importer validates the grid, converts images to RGBA, aligns each visible
frame to a common 12-pixel lower margin, writes standardized filenames, creates
`hero-animation-manifest.json`, and makes `hero-preview.png` for Settings.

## Relevant code

```text
tools/import-hero-animation-sheets.py
apps/web/src/worldConfig.ts
apps/web/src/components/PhaserWorld.tsx
apps/web/src/components/SettingsPanel.tsx
```

`worldConfig.ts` defines texture files, frame rates and the training mappings.
`PhaserWorld.tsx` loads all seven sheets and builds Phaser animations whose
frames refer to the relevant texture.

## Positioning

The importer leaves 12 transparent pixels below the visible sprite. The Phaser
sprite is therefore placed at:

```ts
WORLD.walkY + HERO_FRAME.bottomPadding * WORLD.heroScale
```

This keeps the visible feet on the path while retaining a bottom-centered
origin for all animations.

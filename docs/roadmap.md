# Roadmap

## Current v0.3 MVP

- Mobile-first pixel-art path.
- Persistent local hero state.
- Training overlays for vocabulary, listening, pronunciation, grammar-style choice, and letters.
- Monster-gated levels and capped attributes.
- Level-unlocked shop backlog.
- Web Audio sound effects.

## Next iterations

1. Replace CSS pixel sprites with real sprite sheets while keeping `PixelWorld` as the renderer adapter.
2. Add a small content-authoring screen for editing words, translations, distractors, letters, and story milestones.
3. Add human Armenian audio files and prefer them over browser TTS.
4. Add a real sentence-order activity with sentence data in the content pack.
5. Add parent profiles and multiple child profiles.
6. Add private invite-code friend groups and weekly non-public leaderboards.
7. Add export/import for community language packs.
8. Add optional speech/pronunciation providers behind a provider interface.

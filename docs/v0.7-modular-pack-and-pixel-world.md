# v0.7 modular pack and pixel world notes

v0.7 is a structural refactor. The old single `pack.json` has been replaced by a modular language-pack folder.

## Pack rule

One pack represents one target/base pair.

Examples:

```text
hy-eastern-it   Eastern Armenian taught through Italian
hy-eastern-en   Eastern Armenian taught through English
hyw-western-fr  Western Armenian taught through French
```

The app does not offer a separate base-language selector. Interface text, translations, levels, enemies, tasks, and audio all come from the selected pack.

## Pack layout

```text
content-packs/hy-eastern-it/
  pack.yaml                 metadata and file map
  interface.yaml            UI/menu/story labels for this pack
  tags.yaml                 controlled semantic tags
  tasks.yaml                training options and session length
  levels.yaml               stat caps, fight gates, timers, complexity
  enemies.yaml              monsters and monster topic tags
  story.yaml                next-task milestones
  dictionary/
    words.jsonl
    letters.jsonl
    sentences.jsonl
  audio/
    auto/
    human/
```

## Level gating

A fight has two steps:

1. The monster refuses if minimum requirements are missing.
2. Once requirements are met, the fight length depends on readiness.

At minimum readiness, the fight uses `at_min_questions`. At maxed stats, the fight approaches `min_questions`, but the engine never goes below 10 questions.

Pack authors can edit this in `levels.yaml`:

```yaml
levels:
  - number: 1
    stat_cap: 8
    max_complexity: 2
    unlock_requires:
      completed_training_sessions: 10
      answered_fight_questions: 10
      min_stats:
        power: 3
        shield: 3
        accuracy: 3
        strategy: 3
    fight:
      min_questions: 10
      at_min_questions: 25
      timer_seconds: 10
```

## Semantic tags

Tags are controlled in `tags.yaml`. Words and sentences should use those tags so monsters can prioritize suitable questions.

Example enemy:

```yaml
enemies:
  - id: mist_goblin
    level: 1
    semantic_tags:
      - greeting
      - basic
      - family
```

During fights, the learning engine first tries to choose questions with those tags and within the current level complexity.

## Pixel world changes

The world is now a side-scroller-inspired pixel scene rather than a vector meadow. The path is rendered as terrain inside the game window, not behind the HUD. Layers move at different speeds:

- soft distant mountains and hills
- far scenery such as village houses and ruins
- path-side scenery and encounters
- hero and monster
- foreground flowers, mushrooms, and funny objects

Debug path information is hidden unless Settings -> Debug is enabled.

## Profile changes

Clicking the hero name at the top opens a profile switcher. The full Settings panel still supports adding profiles, renaming, and editing appearance. Progress is local-browser only for now, but storage is isolated by pack and child profile ID so a backend can replace it later.

# v0.10.6 simplified sprite guides

This graphics-only update simplifies the hero sprite system.

## Main changes

- The hero always has sword, shield, and light armor baked into the base sprite.
- The Phaser renderer no longer loads or synchronizes sword, shield, or armor overlay sheets.
- Settings now exposes one canonical hero sprite set: `hero-adventurer.png`.
- The active hero sheet uses a clearer guide layout:

```text
128x128 px per frame
8 columns
12 rows
768x1152 px total
transparent background
```

Rows:

```text
0 idle
1 walk
2 jump
3 attack_1
4 attack_2 / special
5 defend / parry
6 hit_fall
7 victory_jump
8 training_strength
9 training_defense
10 training_precision
11 training_stamina
```

## Object guide sheets

Objects were regenerated as larger, clearer guide sprites:

```text
objects-large.png   128x128 frames
objects-small.png   64x64 frames
objects-front.png   96x96 frames
training-stations.png 96x96 frames
companion-dragon.png 48x48 frames
```

The point is not final art polish. The point is a clean source sheet with strong silhouettes that can be run through an image-generation or upscaling workflow without fighting the engine.

## New script

```bash
npm run assets:generate-guides
```

This regenerates the simplified guide sprites and then syncs the asset pack into the runtime folder.

Use normal manual-art workflow after editing:

```bash
npm run assets:sync
```

# v0.11.6 — Merged contributor art and improved monsters

This release merges the contributor-supplied `cc0-pixel-v10` top-level art
into the current repository while preserving the complete v0.11.5 labyrinth
asset directory.

## Merged side-scroller art

The following source-of-truth files now come from the uploaded asset bundle:

```text
layer-00-sky.png
layer-01-far-mountains.png
layer-02-far-hills.png
layer-03-mid-hills.png
layer-04-sparse-forest.png
layer-05-village-back.png
layer-06-path-ground.png
objects-large.png
objects-small.png
objects-front.png
training-stations.png
hero-*.png
companion-*.png
```

The labyrinth assets remain under:

```text
asset-packs/cc0-pixel-v10/labyrinth/
```

They are not replaced by top-level asset-pack imports.

## Layer-size adjustment

The uploaded hill layers use these dimensions:

```text
layer-02-far-hills.png  768 x 146
layer-03-mid-hills.png  768 x 128
```

`apps/web/src/worldConfig.ts` was updated so Phaser crops each tile layer at
its real height rather than repeating or truncating the image vertically.

## Improved monster sheet

The side-scroller monsters are now built at 96 x 96 pixels per frame:

```text
monsters.png  384 x 576
4 columns x 6 rows
```

Columns are idle, hurt, attack and defeated. Rows are goblin, bat, troll,
dragon, wizard and blob.

The image-model concept source and six transparent cutouts are retained in:

```text
asset-packs/cc0-pixel-v10/sources/monster-art/
```

Regenerate the sheet after refining a cutout:

```bash
npm run assets:generate-monsters
```

The command writes `monsters.png` and then mirrors the complete asset pack into
`apps/web/public/assets/pixel/`.

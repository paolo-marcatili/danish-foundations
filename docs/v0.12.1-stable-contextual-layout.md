# v0.12.1 — stable contextual layout and audio eligibility

This release completes the integration that began after v0.12.0.

## Layout

- The Phaser side-scroller remains mounted in a stable 16:9 viewport.
- Standard mode uses a two-column shell: game world on the left; stats, task/story, training menu, or shop on the right.
- Training and fights keep the world visible and use the contextual right panel for questions, answers, energy, hearts, and feedback.
- Narrow and simulated-phone layouts place the fixed world above an internally scrolling contextual panel.
- Train, Fight, and Shop use a reserved action row and do not cover the canvas.
- The device simulator is session-scoped, has an external Exit simulation button, supports Escape, and allows scrolling inside the simulated device.

## Labyrinth

- Selecting Labyrinth opens it directly without the side-scroller approach delay.
- The dragon remains in the side-scroller but is not rendered on the labyrinth map.
- During every active labyrinth question, the question/encounter view uses the complete contextual panel and the log is temporarily hidden.
- The map remains mounted and stationary; the log returns after the question and retains its component state.
- Empty-room movement is not added to the adventure log, including when older saves are restored.
- Resolved events and explored floors remain clearly visible.
- The four user-supplied wall files are copied without cleanup or modification.

## Question and audio safeguards

- Armenian-letter choices display only a Latin sound/transliteration label; Armenian example words are not shown before answering.
- Human-only comprehension requires an approved human recording.
- Human-and-automatic comprehension requires a real non-draft audio reference.
- Items without playable audio are excluded before question generation.
- Labyrinth and fight selection can fall back to another eligible focus instead of creating a silent question.
- Playback failures return a failure result and produce a development warning instead of a generic sound cue.

## Verification

```bash
npm install
npm run assets:sync
npm run validate:content
npm run check
npm run build
npm run dev
```

# v0.8.1 quick fixes

This patch cleans up the Phaser side-scroller and audio-dependent question behavior.

## Graphics

- The sky is now a fixed image, not a scrolling tile layer, so the sun appears once.
- Parallax layers still move at different speeds, but distant objects are faded through their palette colors rather than runtime transparency.
- Scenery objects are anchored to the ground line instead of appearing underground.
- The active pixel assets are real PNG sprite sheets in `apps/web/public/assets/pixel/`.
- The same sprites are mirrored in `asset-packs/cc0-pixel-v08/` so the asset pack contains the runtime sprites and can be replaced by artists later.

## Audio-dependent questions

When Settings -> Audio lessons is set to `Solo voci reali`, the app no longer uses automated-only words for listening/pronunciation questions. If no human audio exists for that training type, the training refuses to start and asks the parent to record human audio or enable automatic audio.

In fights, audio-dependent focus types are skipped when only human audio is allowed and no matching human-audio items are available.

## Grammar/puzzle questions

Puzzle/grammar questions no longer show the audio replay button, because hearing the full target sentence makes the exercise too easy.

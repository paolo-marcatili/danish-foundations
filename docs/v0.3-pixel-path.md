# v0.3 Pixel Path notes

This iteration changes the MVP from a 3D Babylon.js arena to a mobile-first 2D pixel-art path.

## Main design decisions

- The path is always the home screen. Training, fight, shop, and story are overlays on the same scene.
- The hero walks by default. When a training session or fight starts, the path pauses and the relevant challenge object or monster appears on the path.
- Hero status is persisted locally with `localStorage` through `apps/web/src/storage.ts`.
- Sound effects are generated with Web Audio in `apps/web/src/audio.ts`; no external sound files are needed for basic feedback.
- Level progression is monster-gated. Training can increase stats, XP, coins, mastery, and path distance, but only `markEnemyDefeated` can increase `state.level`.
- Stats are capped by level with `getLevelStatCap` so training remains useful without encouraging endless grinding.

## Stat mapping

| Training focus | Hero attribute |
| --- | --- |
| Vocabulary recognition | Power |
| Listening comprehension | Shield |
| Pronunciation / repeat-after-me | Accuracy |
| Grammar-style sentence/word choice | Strategy |
| Armenian letter recognition | Accuracy |

## Current MVP limitations

- Pronunciation is still a repeat-and-recognize activity, not real pronunciation scoring.
- Grammar includes a small starter set of sentence-order items, but all Armenian sentences still need fluent/native-speaker review.
- The pixel art is CSS-based for fast iteration. Future asset packs can replace it with sprite sheets.

# v0.10.7 Hero frame clipping fix

This is a small graphics-only fix after the simplified sprite guide update.

## Problem

Some 96x96 hero guide frames clipped visible parts of the character:

- the sword could leave the frame during training or attack poses;
- the head could leave the frame during jump/victory poses;
- the fall row looked cramped and uneven.

## Fix

The active hero guide sheet now uses larger 128x128 frames:

```text
hero-adventurer.png
frame size: 128 x 128 px
columns: 8
rows: 12
sheet size: 1024 x 1536 px
```

The Phaser renderer was updated in `apps/web/src/worldConfig.ts`:

```ts
frameWidth: 128,
frameHeight: 128
```

The guide generator was also changed so all hero poses remain inside the frame:

- jump is now a bounded hop pose, not a large vertical displacement;
- victory is now a celebration pose, not a high jump;
- attack and training sword arcs are shorter;
- precision/stamina training props remain inside the cell;
- the fall row has clearer recoil and grounded fall frames.

A bounding-box check was run over all 96 hero frames after generation; no frame touches the sprite-cell edges.

## Workflow

To regenerate the safe guide sheet:

```bash
npm run assets:generate-guides
```

To sync edited assets into the runtime folder:

```bash
npm run assets:sync
```

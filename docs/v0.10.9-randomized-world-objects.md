# v0.10.9 - Randomized sparse world objects

This release refactors decorative object spawning in the Phaser side-scroller.

## Changes

- Large-object frames are now `256 x 256` pixels. The full eight-frame sheet is
  `2048 x 256` pixels.
- Decorative objects are grouped by their configured world layer and inherit
  the exact parallax speed of that layer.
- Each object layer uses a shuffle bag, so object kinds appear in a newly
  randomized order before repeating.
- The first item of a reshuffled bag cannot repeat the final item of the
  previous bag when another object kind is available.
- Objects receive a random scale, horizontal flip, vertical ground jitter, and
  randomized spacing every time they are recycled.
- Objects recycle relative to the rightmost visible edge in their own layer,
  preventing overlap when several sprites leave the screen close together.
- Object density and gap ranges are intentionally sparse.
- Encounter clearance now relocates decorations instead of hiding them and
  making them reappear behind the hero.
- Training animations remain looped while a training session is active.

## Main tuning file

Edit:

```text
apps/web/src/worldConfig.ts
```

The main values are under `WORLD_OBJECT_LAYERS`:

- `count`: number of live sprites in the layer;
- `minGap` / `maxGap`: randomized spacing;
- `initialMinX` / `initialMaxX`: initial placement range;
- `minScale` / `maxScale`: visible-size range;
- `yJitter`: small vertical variation around the layer ground line;
- `flipChance`: probability of horizontal mirroring;
- `avoidEncounterRadius`: space reserved around a monster or training station.

The runtime shuffle and recycling logic is in:

```text
apps/web/src/components/PhaserWorld.tsx
```

## Asset dimensions

```text
objects-large.png: 2048 x 256, eight horizontal 256 x 256 frames
objects-small.png: 512 x 64, eight horizontal 64 x 64 frames
objects-front.png: 576 x 96, six horizontal 96 x 96 frames
```

After editing source assets in `asset-packs/cc0-pixel-v10/`, run:

```bash
npm run assets:sync
```

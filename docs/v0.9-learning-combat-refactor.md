# v0.9 learning and combat refactor

v0.9 refactors the core learning and fight mechanics while keeping the v0.8 Phaser side-scroller.

## Training/stat model

The four main trainings are now:

- `vocabulary` -> `strength` / Forza
- `comprehension` -> `defense` / Difesa
- `grammar` -> `precision` / Precisione
- `pronunciation` -> `stamina` / Resistenza

Armenian letters are treated as low-complexity vocabulary practice.

## Training completion

Training sessions only count when mistakes are within the pack-defined limit in `content-packs/hy-eastern-it/tasks.yaml`:

```yaml
training_completion:
  max_mistakes: 3
```

If a child makes too many mistakes, the session becomes practice only: no completed session count, no stat increase, and no progression reward.

## Fight formula

The fight formula uses linear stat caps and a sigmoid precision-vs-defense curve.

- Strength is maximum possible outgoing damage.
- Precision determines how close the hit gets to maximum damage.
- Defense reduces damage from mistakes.
- Stamina increases hero energy.

The multiplier is centered so equal precision and defense gives about half maximum damage.

## Fight length and ending

Monster energy is at least:

```text
level_strength_cap * 10
```

Before 10 answered questions, monster HP cannot drop below 1. From question 10 onward, HP at or below zero ends the fight immediately.

The level file also defines a maximum number of mistakes allowed to win:

```yaml
fight:
  max_mistakes_to_win: 4
```

## Feedback

Answer buttons now show the answer state directly:

- correct answer: green;
- selected wrong answer: red;
- correct answer still shown in green after a mistake.

Fights also show a compact combat card with damage dealt, damage taken, and absorbed/reduced damage.

## Item memory

Each child now stores item-level practice memory for words, letters, and grammar items:

- last asked time;
- whether the last answer was wrong;
- seen/correct/wrong counts;
- success streak;
- mastery;
- next review time.

Question selection prioritizes matching tags and complexity, then recently wrong items, due items, older items, and new items.

## Pre-reading support

Words can include an optional `emoji` field. Low-complexity vocabulary questions may use emoji-to-Armenian and Armenian-to-emoji variants.

## Pronunciation placeholder

Pronunciation does not use speech recognition yet. It uses fast sound-form exercises such as transliteration and syllable matching, suitable for timed fights.

## Audio

Menu click sounds are disabled. Audio now focuses on meaningful events such as correct/wrong answers, attacks, parries, rewards, and level-up.

# v0.11.2 — Enchanted Forest Ruins labyrinth

This release adds the first mixed-skill labyrinth training mode and completes
the 25-frame dragon companion integration.

## Labyrinth rules

The default `hy-eastern-it` pack defines the labyrinth in:

```text
content-packs/hy-eastern-it/labyrinths.yaml
```

The current configuration uses:

```text
Theme: enchanted forest ruins
Map: 7 x 7 procedurally generated perfect maze
Perspective: isometric SVG map
Fog: current cell plus connected adjacent cells
Hearts: 5
Question target: 35
Allowed range: 30–40
Minimum per learning focus: 6
Monster encounters: 3
```

The four rune encounters cover vocabulary, comprehension, grammar, and
pronunciation. The treasure guardian does not activate until all four runes
have been collected. Mixed monster and guardian questions are weighted toward
the learner's weaker attributes.

## Rewards

A successful run:

- adds one point to every attribute, capped by the current level;
- counts as one completed training session for the current level;
- may award coins or one level-unlocked, unowned shop item;
- retains XP, path progress, and item-memory updates earned by its questions.

A failed or explicitly abandoned run keeps only spaced-review memory. It does
not award attributes, session credit, coins, item rewards, XP, or path progress.

## Autosave and profiles

The active run is stored separately for each child profile in browser/app local
storage. Stable states are saved after movement and after each completed answer
feedback interval. A page closure during answer feedback restores the last
answerable question rather than a locked transient state.

A paused run is rebased onto the latest learner state when resumed. This avoids
losing progress made elsewhere and merges practice memory by the latest
`last_asked_at` timestamp.

## Dragon animations

The dragon uses two independent 5 x 5 sheets with 25 frames each:

```text
companion-dragon-walk.png
companion-dragon-victory.png
```

The walk animation loops while the hero travels. The first walk frame is used
while stopped. The full victory animation plays after fight and labyrinth
victories.

To replace the source sheets:

```bash
npm run assets:import-companion -- /absolute/path/to/dragon-sheets.zip
npm run assets:sync
```

## Recommended manual test

1. Start a new child profile.
2. Open Train → Labyrinth.
3. Move to several cells, pause, reload the page, and resume.
4. Verify fog, explored cells, hearts, and question count persist.
5. Lose all five hearts and verify no rewards are granted.
6. Start another run, collect all four runes, and reach the treasure.
7. Verify every non-capped attribute gains one point and the level's training
   session count gains one.
8. Repeat with the dragon item owned and verify the walk/victory animations.
9. Test `human_only` audio mode; the labyrinth should refuse to start when no
   eligible human comprehension audio exists.

# v0.10 graphics polish

This graphics-only update replaces the rough v0.9 placeholder sprites with a cleaner Phaser 2D side-scroller asset set.

## What changed

- Hero sprite sheets now use 48x48 frames with a larger action set.
- The Phaser renderer loads frame-based animations for walk, run, attacks, throw, parry, hit, fall, victory, training actions, and the funny fart action.
- Monster sprites were regenerated at 48x48 with clearer idle, hit, attack, and defeat frames.
- Training stations were regenerated as larger 64x64 sprites with no text labels inside the world scene.
- The path/ground is wider and more readable, with a grassy edge, broad path surface, and dirt below it.
- Parallax layers are calmer: fixed sky, slow mountains, distant forest, village, ground, and sparse foreground objects.
- Decorative objects are now scenery-relevant: grass, flowers, rocks, logs, stumps, bushes, mushrooms, signs, trees, cottages, and caves.
- Random unrelated objects such as cakes, gems, and diamonds were removed from the active scenery pool.
- Object spawning was tightened so objects stay anchored to the path/ground instead of floating or appearing underground.

## Asset locations

Runtime assets are served from:

```text
apps/web/public/assets/pixel/
```

The mirrored editable asset pack is:

```text
asset-packs/cc0-pixel-v10/
```

The assets are generated by:

```bash
python tools/generate-pixel-assets.py
```

The generated placeholder assets are released as CC0/public domain and can be replaced by a more polished permissive/CC0 art pack later.

# v0.5 browser merge, balance, and path fixes

This iteration addresses the first real play-test feedback after the pixel-art MVP.

## Gameplay changes

- The path generator now fills the whole viewport. Objects enter from the right, travel left, and disappear outside the left edge instead of respawning near the middle.
- The road is now a true curving band with variable width. The hero and encounter sprites use the current path position so they visually follow the route.
- Background mountains are anchored behind the meadow instead of floating above it.
- Far, path-side, hero/enemy, and foreground layers are separated more clearly.
- Added more funny scenery objects such as frogs, gems, bushes, beehives, owls, balloons, mushrooms, and snails.
- Pronunciation questions no longer reveal the translation or transliteration in the prompt/options. The child hears the word, repeats it, then chooses the Armenian word that was heard.
- The hard-distractor star was removed from answer buttons. Hard distractors are still used internally, but the child no longer sees a confusing marker.

## Balance changes

- Level stat caps now increase by larger steps: level 1 cap is 5, then +5 per level.
- Monsters have suggested minimum attributes. Being under-trained reduces damage and increases damage taken; being trained above the recommendation makes fights much easier.
- Shop items can require minimum attributes as well as coins and level.
- Levels are still monster-gated: training alone never levels up the hero.

## Content/admin changes

- The Armenian starter pack now includes 104 vocabulary items, 40 sentence-order items, and 12 letter items.
- New words/sentences without human recordings automatically get browser-TTS fallback metadata. Running `npm run content:auto-audio` creates eSpeak `.wav` preview files for repository content.
- The admin panel can save contributions directly into the browser/local app state. This is useful on mobile and for quick testing.
- The admin panel can import contribution JSON files and merge them locally.
- Existing words and sentences in the admin vocabulary list are clickable, so contributors can load an entry and append another recording without retyping the text.
- The terminal merge script now accepts MediaRecorder data URLs such as `data:audio/webm;codecs=opus;base64,...`.

## Important limitation

A normal browser or mobile webview cannot silently write back into the Git repository. The in-page merge saves content to the local browser copy of the pack. To contribute upstream, export the contribution or local pack and commit it through Git.

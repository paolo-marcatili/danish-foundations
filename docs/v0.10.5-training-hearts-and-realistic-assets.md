# v0.10.5 training hearts and realistic scenery assets

This update contains small gameplay-balancing changes plus a graphics asset refresh.

## Training sessions

Training no longer grants coins for every individual correct answer. A completed training session grants a small completion reward only. This makes shop items require more sustained practice.

The training mistake limit is now presented as hearts/lives. When the hearts reach zero, the session ends immediately and does not count as completed. The temporary item/letter/grammar review memory is still retained so wrong items can reappear later, but the session does not grant an attribute point or completed-session credit.

Current configuration remains in:

```text
content-packs/hy-eastern-it/tasks.yaml
```

```yaml
training_completion:
  max_mistakes: 3
```

With three hearts, the third mistake ends the session as a failed practice.

## Quiz variants

The `missing_word` grammar variant is disabled for now because several Armenian sentence items can have more than one plausible missing word. Grammar still supports sentence choice, translation choice, and tap-in-order exercises.

## Economy

Shop prices were increased and training rewards were reduced. This is intentionally grindier: cosmetic/stat items should require repeated successful training and monster victories.

## Graphics

A new DALL-E style reference was generated and stored in:

```text
asset-packs/cc0-pixel-v10/sources/dalle-style-reference-v0105.png
```

Runtime scenery is still game-ready PNG art generated into the asset pack, with fixed dimensions for Phaser. The new script is:

```bash
npm run assets:generate-realistic
```

This regenerates the more realistic-style parallax and object assets, then syncs them to:

```text
apps/web/public/assets/pixel/
```

To hand-edit assets, edit the source files in:

```text
asset-packs/cc0-pixel-v10/
```

then run:

```bash
npm run assets:sync
```

## World placement tuning

Object sizes and path placement are controlled in:

```text
apps/web/src/worldConfig.ts
```

The hero walk line was moved to:

```ts
walkY: 427
```

Large objects behind the hero are intentionally much larger now. Foreground objects are also larger, so bushes and rocks can partially cover the hero's feet while passing.

# v0.6 settings, path, profiles, and content selection

## What changed

- Added child profiles so multiple kids can keep separate heroes and progress on the same device.
- Added Settings for profile selection, hero name, appearance, graphics pack, base language, audio mode, debug mode, reset, and dictionary editing.
- Hid path/debug numbers by default. Enable debug mode in Settings to show distance, path shape, and stat cap.
- Reworked the pixel world with an explicit SVG path, improved layering, and off-path scenery placement.
- Added semantic `tags` and `complexity` to vocabulary and sentence-order content.
- Fight question selection now uses monster tags and level complexity.
- Default lesson audio is human-only. Automated audio is opt-in.

## Content selection

Each word/sentence can have:

```json
{
  "difficulty": 2,
  "complexity": 2,
  "tags": ["food", "home"]
}
```

The learning engine uses the hero level to choose a maximum complexity. Monsters also have tags. During fights, the engine prefers questions that match both the level complexity and the monster tags.

## Profiles

Progress is stored per content pack and per child profile:

```text
hero-language-camp:v0.6:state:<pack_id>:<profile_id>
```

This lets siblings use the same browser without overwriting each other's level, coins, stats, or inventory.

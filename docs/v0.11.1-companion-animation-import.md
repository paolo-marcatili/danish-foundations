# v0.11.1 companion animation import

The dragon companion now uses two independent 25-frame, 5 x 5 sprite sheets:

- `companion-dragon-walk.png`
- `companion-dragon-victory.png`

Source sheets belong in:

```text
asset-packs/cc0-pixel-v10/sources/companion-animation-sheets/
```

Import and normalize a ZIP or directory:

```bash
npm run assets:import-companion -- /absolute/path/to/dragon-sheets.zip
npm run assets:sync
```

The importer verifies a 5 x 5 square-frame grid, preserves transparency, aligns
all frames to a common lower baseline, writes a manifest, and creates a preview.

Runtime behavior:

- walking on the side-scroller: full walk sheet loops;
- stopped during training/fighting: first walk frame is used as idle;
- fight victory and labyrinth treasure victory: victory sheet plays once;
- companion remains cosmetic.
